#### Project Overview

Designed and built an interactive analytics dashboard to track and evaluate a subscription business's financial performance, translating raw transactional data into actionable revenue insights. From defining key metrics to designing a dashboard that supports strategic, data-driven decision-making.

#### Goal

The goal of this project was to develop a comprehensive revenue analytics dashboard that enables stakeholders to monitor financial health, identify the key drivers behind revenue growth and churn, and make informed decisions to optimize business performance and profitability.

**Tools & Tech Stack**

- **PostgreSQL** — source database for transactional and user data
- **SQL** — writing queries to extract, filter, and aggregate data
- **DBeaver** — database client used to connect to PostgreSQL and run SQL queries
- **Tableau** — data visualization and dashboard building

#### What the Dashboard Delivers

- **Core SaaS metrics**, including MRR, ARPPU, New MRR, Expansion/Contraction MRR, Churn Rate, Revenue Churn Rate, Customer Lifetime (LT), and Customer Lifetime Value (LTV)
- **Interactive filters** by date, user language, and user age, allowing flexible, segmented analysis
- **Month-over-month breakdowns** of the key factors driving changes in revenue and paid user count
- **Five+ visualizations** designed following core data visualization best practices — the 5-second rule, clear visual hierarchy, precise metric labeling, and a consistent, purposeful color scheme

#### Skills Demonstrated

Financial and revenue analysis, dashboard design, data visualization, metric definition, and translating business questions into clear, decision-ready reporting tools.
